\## 🗄️ Резервное копирование БД Firebird (ГАС «Правосудие»)



Набор `.bat`-скриптов для обслуживания СУБД \*\*Firebird 1.5\*\*:



\* \*\*`backupDbFirebirdGAS/FireBird.bat`\*\* — останавливает службу Firebird, выполняет резервное копирование файлов `\*.GDB` и запускает службу обратно.

\* \*\*`backupDbFirebirdGAS/avtoFireBird.bat`\*\* — полностью автоматизирует процесс создания прямой копии файла БД при остановленном сервере.

\* \*\*`backupDbFirebirdGAS/sudimost.bat`\*\* — узкоспециализированный скрипт бэкапа файлов БД.

\* \*\*`sizeDbFirebirdGAS.bat`\*\* — фиксирует текущий размер файлов баз данных `\*.GDB` для контроля роста.



> ⚠️ \*\*Важно:\*\* Перед запуском прямого копирования файлов БД убедитесь, что службы Firebird полностью остановлены во избежание повреждения данных.

\## 📡 Бэкап конфигураций Nokia MRBTS с FTP



Модульное решение в папке `backupFtpNokiaMrbts/` разделено на два независимых этапа для повышения отказоустойчивости:

1\. \*\*Выгрузка с FTP\*\* (`startBackupFilesFtp.ps1` ➔ `backupFilesFtp.py`) — подключение к FTP-серверу, скачивание целевых директорий и упаковка в `.zip` архив на локальном узле.

2\. \*\*Перемещение в сеть\*\* (`startBackupFiles.ps1` ➔ `backupFiles.py`) — перенос готового `.zip` архива в конечную сетевую директорию.



\### Основные компоненты:

\* `scripts/importKeys.py` — безопасный импорт ключей и учетных данных.

\* `scripts/replaceFiles.py` — логика перемещения, перезаписи и контроля целостности файлов.

\* `scripts/testLibrary.py` — проверка и валидация установленных библиотек Python.

\* `mrbtsRegs/` — адаптированные скрипты (`mrbtsbackup\*.ps1`) и инструкция (`readme.docx`) для других регионов.



\### Настройка перед запуском:

1\. Заполните \*\*`backupFtpNokiaMrbts/.env`\*\* (или `scripts/.env`) — укажите адреса, логины и пароли для FTP и сетевых шар.

2\. Настройте \*\*`backupFtpNokiaMrbts/config.txt`\*\* — пропишите пути и параметры \*\*Proxy\*\* (обязательно для работы в изолированных корпоративных сетях).



\### Запуск и автоматизация (Windows Task Scheduler):

Для ручного запуска выполните в PowerShell:

```powershell

.\\startBackupFilesFtp.ps1

.\\startBackupFiles.ps1

```



Для регулярной работы создайте две задачи в \*\*Планировщике задач Windows\*\*:

\* \*\*Задача 1 (Выгрузка с FTP):\*\* Триггер — ежедневно в `01:00`. Действие — запуск программы `powershell.exe` с аргументами:

&#x20; ```text

&#x20; -ExecutionPolicy Bypass -File "C:\\путь\_к\_проекту\\startBackupFilesFtp.ps1"

&#x20; ```

\* \*\*Задача 2 (Перенос в сетевую папку):\*\* Триггер — после завершения первой задачи. Действие — запуск скрипта `C:\\путь\_к\_проекту\\startBackupFiles.ps1`.

\## 🦠 Восстановление данных с зараженных USB-накопителей



Скрипт \*\*`FlashDriveRecovery.bat`\*\* предназначен для возврата доступа к файлам, скрытым троянскими программами на флеш-накопителях (симптом: флешка выглядит пустой или содержит один ярлык/папку с именем самой флешки, но место на диске занято).



\### Порядок действий:

1\. \*\*Не открывайте\*\* подозрительную папку/ярлык внутри флешки.

2\. Запустите проверку системы (например, через \*\*Kaspersky Free\*\*: \*Рекомендации по устранению проблем ➔ Устранить ➔ Перезагрузить компьютер\*).

3\. Подключите флешку и дождитесь, пока антивирус удалит исполняемый файл вируса.

4\. Скопируйте файл \*\*`FlashDriveRecovery.bat`\*\* в корень зараженной флешки и запустите его — скрипт снимет системные и скрытые атрибуты (`attrib -s -h`) и вернет доступ к вашим папкам.
