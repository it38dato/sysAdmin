Перед бэкапом файлов БД необходимо убедиться что отстановились службы БД Firebird.

Процесс резервного копирования в папке backupFtpNokiaMrbts разделен на два независимых этапа для обеспечения отказоустойчивости:

* Выгрузка с FTP (startBackupFilesFtp.ps1 -> backupFilesFtp.py). Скрипт подключается к FTP-серверу, скачивает целевые файлы/директории и упаковывает их в .zip архив на локальном узле.
* Перемещение в сетевую папку (startBackupFiles.ps1 -> backupFiles.py). Скрипт подхватывает готовый .zip архив из локальной директории и безопасно переносит его в конечную сетевую папку.

Для работы скриптов в папке backupFtpNokiaMrbts необходимо корректно заполнить два файла в корне проекта:
backupFtpNokiaMrbts/scripts/.env - Заполните адреса, логины и пароли к FTP и сетевым ресурсам
backupFtpNokiaMrbts/scripts/config.txt - Обязательно укажите настройки proxy для корректной работы библиотек в изолированной корпоративной сети. Перед запуском внимательно проконтролируйте валидность всех остальных данных внутри файла.

Запуск проекта в папке backupFtpNokiaMrbts осуществляется через PowerShell-скрипты автоматизации, которые подготавливают окружение и вызывают основные Python-файлы.
Вы можете поочередно запустить цепочку скриптов из консоли:
.\\startBackupFilesFtp.ps1
.\\startBackupFiles.ps1
Для промышленной эксплуатации настройте выполнение скриптов через Планировщик задач (Task Scheduler):

* Создайте Задачу для FTP-бэкапа: Триггер - Например, ежедневно в 01:00, Действие - Запуск программы, powershell.exe, Аргументы - -ExecutionPolicy Bypass -File "C:\\путь\_к\_проекту\\startBackupFilesFtp.ps1"
* Создайте Задачу для перемещения файлов. скрипт: C:\\путь\_к\_проекту\\startBackupFiles.ps1

* Открываем флешку после удаления вируса (пустой файл, хотя система показывает, что флешка заполнена, Он содержит зашифрованные файлы)
